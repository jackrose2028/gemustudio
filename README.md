# Emu-Mod!

A seven-system retro emulator shelf. No ROMs are bundled; users can import their own supported ROM files, ZIP archives, or folders.

- The library is hidden initially. Click the controller icon to reveal locally imported games.
- Imports, ROM data, and source ZIP archives are stored in browser IndexedDB and stay on that device. The Delete Games button clears imported games, archives, and saved states from local storage.
- Supported systems are Atari 2600, NES, Game Boy, Super Nintendo, Game Gear, Nintendo 64, and Game Boy Color.
- Emulator settings are available from the gear button.
- EmulatorJS-mod 4.3.0-pre is bundled under emulator-mod/ and powers the player.
